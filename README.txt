FOLLOW-UP FIX FOR PINKY'S ICE CREAM RACE

This corrects two bugs from the first race polish:
1) mouth-open overlays were too high on the face for some characters
2) a grey/transparent seam could still show between head and body while eating

INSTALL
1. Merge this ZIP's tools and .github folders into your cloned repo.
2. Commit and Push origin in GitHub Desktop.
3. GitHub > Actions > 'Fix Pinky's eating animation' > Run workflow (main).
4. When green, manually run 'Publish Curb Fighters to GoDaddy'.

No extra Python packages are required on your Mac.
